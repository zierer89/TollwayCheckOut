# Illinois Tollway Equipment Checkout

Static GitHub Pages prototype for vehicle and equipment checkout sheets.

## Current build
- Illinois Tollway splash screen
- Responsive iPad / phone layout
- Equipment checkout menu
- Placeholder screen under each equipment type
- Basic installable/offline support through a web app manifest and service worker

## Upload to GitHub
1. Create a new GitHub repository.
2. Upload every file and the `assets` folder from this project.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the web address for the app.
